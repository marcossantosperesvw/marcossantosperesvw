## 🚀 Featured Project

### [Chat Jogos](https://github.com/marcossantosperesvw/chatbot)

Chatbot web especializado em jogos eletrônicos, desenvolvido com
Next.js, TypeScript e FastAPI.

- Agente de IA integrado à OpenAI.
- Consulta ao catálogo IGDB para recomendações contextualizadas.
- RAG com documentação local para fundamentar respostas.
- Busca e reprodução de tutoriais do YouTube.
- Histórico de conversas durante a sessão da aba.
- Testes automatizados no frontend e no backend.
